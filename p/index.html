01 — Address

npub or NIP-05

npub is the portable public key. NIP-05 is a human-readable alias like you@yourdomain.com that resolves to the same key.

02 — Ownership

Only the key can edit

Edits are signed with a Nostr signer (NIP-07 or NIP-46). A visitor can read every field but cannot change one; relays reject a write signed by another key.

03 — Portability

Your data leaves with you

The portfolio is a NIP-78 app-data event (kind 30078) on relays you choose. Export the JSON at any time; no private drafts are published.

Gallery

Images are compressed in your browser and embedded in the signed event. Video stays a direct public URL because it does not fit inside a relay event.
Drop images here JPEG, PNG, WebP, GIF or AVIF. Each image is resized and compressed before publishing; animated GIFs are stored as a still frame.

How media is stored

  • Uploaded images travel inside your NIP-78 event as compressed data URLs, so they work without a media server. Keep the total under the inline budget shown above, or use a hosted image URL for originals and animation.
  • Video needs a direct MP4 or WebM URL. Upload the file to a media host you control — for example a Blossom or NIP-96 server — then paste the link here.
  • Alt text and captions make the gallery usable for screen readers and give visitors context before they open an item.
  • Relays enforce different event size limits. If publishing fails, remove an inline image or switch it to a hosted URL.
  • Unchecked items stay in this browser as drafts and are never included in the signed public event.
