01 — Address

npub or NIP-05

npub is the portable public key. NIP-05 is a human-readable alias like you@yourdomain.com that resolves to the same key.

02 — Ownership

Only the key can edit

Edits are signed with a Nostr signer (NIP-07 or NIP-46). A visitor can read every field but cannot change one; relays reject a write signed by another key.

03 — Portability

Your data leaves with you

The portfolio is a NIP-78 app-data event (kind 30078) on relays you choose. Export the JSON at any time; no private drafts are published.

How media is stored

  • Upload media sends images or video to the BitOS media service first. If it is unavailable, the Blossom server above is used with a signed upload request. Only the returned https:// links are stored in your event, so keep the files available at those hosts.
  • Images and video can also be added as hosted URLs. Images are never embedded into the event anymore; older profiles with embedded images remain readable and are shown with the legacy budget above.
  • Video previews use a generated poster frame, uploaded alongside the video and stored as a link.
  • Alt text and captions make the gallery usable for screen readers and give visitors context before they open an item.
  • Relays enforce different event size limits. Media links keep the signed event small; publishing only sends the links.
  • Unchecked items stay in this browser as drafts and are never included in the signed public event.
